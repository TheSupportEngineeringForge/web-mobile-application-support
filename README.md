# Web & Mobile Application Support

This repository demonstrates my practical skills in investigating and troubleshooting web services, REST APIs, mobile applications, and interconnected software systems.

The focus is on understanding application behavior, tracing communication between system components, reproducing technical issues, identifying potential failure points, and validating investigation results.

The scenarios involve different technical environments and tools, including HTTP/HTTPS, REST APIs, JSON, Postman, Swagger/OpenAPI, browser DevTools, and mobile application technologies.

**The primary focus is end-to-end technical troubleshooting and problem-solving, rather than any specific application or technology stack.**

## Projects & Investigations

### GeneoGraph - Genealogy Application

**[Product Overview & Support Engineering Research](cases/geneograph/README.md)**

An ongoing Support Engineering research project focused on examining a genealogy and family-history management application.

The project covers:

- Functional analysis of interconnected application modules.
- Documentation of user workflows and cross-module data relationships.
- Investigation of application behavior and potential technical issues.
- Research into data storage, privacy, and security-related functionality.
- Collection of reproducible technical evidence.
- Collaboration with the product developer on findings and clarifications.

**Current status:** Initial Product Discovery completed. Independent functional testing and technical investigations are planned.

The project documentation will be expanded progressively as individual modules are investigated and findings are verified.
